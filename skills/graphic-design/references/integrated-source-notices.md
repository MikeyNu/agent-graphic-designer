# Integrated asset workflows and notices

The asset-generation, integration, and production-quality guidance incorporates and adapts these MIT-licensed packages owned by MikeyNu, inspected on 31 October 2026:

- [Visual Asset Pipeline](https://github.com/MikeyNu/visual-asset-pipeline-plugin/tree/baf5a97be4e93c8b0d7ebbb2ef112e18c19725bd/skills/visual-asset-pipeline), commit `baf5a97be4e93c8b0d7ebbb2ef112e18c19725bd`. Integrated proactive need assessment, medium/layer choices, native-tool discovery, real-byte delivery, alpha checks, coherent families, rendered integration, and recovery.
- [Agent AI Detector](https://github.com/MikeyNu/agent-ai-detector/tree/6f7cba7650409f153888daed9612a545b863fafa), commit `6f7cba7650409f153888daed9612a545b863fafa`. Integrated its production-quality lane: whole/native/context inspection, localized defects, alternative explanations, targeted repair, continuity, and separation of visual quality from origin.

This package is self-contained for those workflows. It does not require either source repository at runtime. It does not embed their optional paid API adapter, transport framework, provenance classifier, audio workflow, or full forensic tooling. Existing local preflight was extended for bounded alpha measurements. No upstream model-detection accuracy claim is adopted. The source pipeline's two-revision default is replaced with progress-based iteration bounded by the user's scope, available tools, and budget.
